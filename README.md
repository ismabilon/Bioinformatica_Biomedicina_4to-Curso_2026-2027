# Bioinformática_Biomedicina_4º-Curso_2026-2027
El presente repositorio centraliza los desarrollos prácticos correspondientes a la asignatura de Bioinformática de 4º curso del Grado en Biomedicina. El objetivo metodológico de este espacio es albergar de forma estructurada las soluciones y los análisis implementados a lo largo del curso, abarcando tanto los talleres prácticos y la práctica opcional de mejora en Python, como el desarrollo integral del proyecto final en forma de aplicación lúdica en Python, además de los análisis estadísticos y moleculares contenidos en el módulo de R, garantizando en todo momento la trazabilidad, el rigor científico y la reproducibilidad de los resultados. Cada script y estructura de código ha sido concebido bajo rigurosos estándares de programación científica para el tratamiento de datos biológicos, facilitando así su auditoría y evaluación técnica.
